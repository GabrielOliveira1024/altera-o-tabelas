# Projeto Banco de Dados

Projeto desenvolvido durante as aulas de Banco de Dados do curso de Análise e Desenvolvimento de Sistemas.

## Tecnologias
- PostgreSQL
- SQL

## Conteúdos praticados
- Criação de tabelas
- Inserção de dados
- Consultas SQL
- Alteração de tabelas e colunas
- Chaves primárias
- Restrições SQL
- Atualização de registros
